# SCMSOS Agents

External agent service for SCMSOS.
Agents live here and call the SCMSOS API (owned by Saurav).

## Setup
1. Copy `.env.example` to `.env` and fill in keys once available.
2. `npm install`
3. `npm run dev`

This is a starter skeleton. Agent logic will be added as the SCMSOS API becomes available.# scmsos-agents
